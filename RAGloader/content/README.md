# Knowledge base content

Place the documents you want to ingest into Pinecone here, organized by type
(e.g. `articles/`, `presentations/`, `text/`). See `RAG_loader_pipeline.ipynb`
for the ingestion pipeline.

Everything in this folder except this README is gitignored. Keep it that way:
source documents are often copyrighted (published papers) or personal (CVs,
statements) and must never be committed to a public repository.
